An entry for make.fun's [Make the Judge Laugh in One Line](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) bounty: a single funny line of at most 200 characters, on any topic — a neighbour's rooster, a 3am retaliation, and a feud with a bird, with the laugh landing on the last five words.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644, after a built-in check that the entry passes the gate (1–200 characters, not only whitespace).
